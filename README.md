# OrfinSupport playground

Built static demo for [OrfinSupport](https://github.com/arconw/OrfinSupport).

[Open the playground](https://arconw.github.io/OrfinSupport/)

Library and editable demo source: [`main`](https://github.com/arconw/OrfinSupport/tree/main).

Source revision: `792b9cac0c93c174391d87a65ef348036cfdb98f`.

This public playground uses sample replies. Run the source locally to connect Orfin to your LLM backend.

The assistant supports 16 languages, with English as the default. Change Language in assistant preferences or in the Playground settings.
